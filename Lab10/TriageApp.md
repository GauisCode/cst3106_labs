#Hospital Triage App Design Document

## Design Overview
This project is to build a sample Hospital triage application. We are trying to build with two users in mind, the patient and the hospital administration staff (admin). The aim is for this to be easy to use for patients while also maintaining the functional logic for the admin.

## Fonts

Merriweather - Titles 
Montserrat - Body
The current iteration of this triage application will user Merriweather for the titles and headings. It will use the bold stroke to clearly designate sections.
The body will use montserrat to have clean and legible font for text and buttons.

## Colour Palette
We will be using the following colours and will divide them between the patient interface and the admin userface.
The Admin userface will use a combination of orange and yellow. Bright and clear with a sense of urgency due to the triage nature.
**Tiger Orange** - F08700
**Golden Orange** - F49F0A
**Bright Amber** - EFCA08
The patient interface will use a blueish green colour palette for a calming & professional effect. The patient users may be in a heightened state and we need them in a clear headspace to input information as clearly, and accurately as possible within a shorter time-frame.
**Light Sea Green** - 00A6A6
**Pale Sky** - BBDEF0



## Application components
### Page 1 - Patient Interface
- Patient Interface: will refer to the interface that the patients will use.
### Page 2 : Administrative Interface
- Admin Interface: will refer to the interface that the hospital administrative staff will use
### User Questionnaire
Located on the patient interface, the patient user will be able to describe their injury and level of pain via a questionnaire form. There will be injury categories, pain levels, and a form submission button.
### Admin Summary
Located on the administrative interface, the admin staff will receive the patient submissions and organize them based on their urgency. They will show up in a table, and they will be able to re-organize them. The table will have a column for the urgency priority, injury type, pain level, and care needed. All of the column categories can be edited by the admin staff. 


## Layout and Navigation
A clear responsive layout with accessibiltiy features is paramount, especially in the patient interface. Having a variety of people using the interface in different states of mind or health means that this application needs to be as accessible as possible. 
## Consistency
Clear consistency in fonts, font size, colour, accessibility and terminology is very important for the type of user that will be using the application.

## User Process/ Functionality
Patients will complete a form to submit a briefing on their medical situation for the hospital staff. 
The hospital staff receive the report and can prioritize the patients by the urgency needed as per the emergency triage protocol.
